APPLICATION PWA — ANGLAIS 1000 MOTS

Fichiers :
- index.html : application
- manifest.json : nom, icônes et paramètres d'installation
- service-worker.js : mise en cache et fonctionnement hors connexion
- icons/ : icônes Android/iPhone

PUBLICATION GRATUITE AVEC GITHUB PAGES
1. Créez un dépôt GitHub public.
2. Déposez TOUS les fichiers et le dossier icons dans le dépôt.
3. Dans Settings > Pages, choisissez Deploy from a branch.
4. Sélectionnez la branche main et le dossier / (root), puis Save.
5. Ouvrez l'adresse HTTPS fournie par GitHub Pages sur votre téléphone.

INSTALLATION
- Android : ouvrez le lien dans Chrome, puis menu ⋮ > Installer l'application
  (ou Ajouter à l'écran d'accueil).
- iPhone : ouvrez le lien dans Safari > Partager > Sur l'écran d'accueil.

NOTE
La première ouverture doit se faire avec Internet pour charger les ressources
externes de mise en forme (Tailwind CSS et Google Fonts). Le Service Worker
met ensuite en cache les ressources consultées pour les prochaines ouvertures.

VOCABULAIRE
L'application charge 1 000 entrées anglais-français à partir de deux listes
publiques alignées par rang du dépôt bukowa/1000-common-words sur GitHub.
Les doublons anglais sont supprimés avant la répartition en 10 carnets.
Certaines traductions d'une liste de fréquence peuvent dépendre du contexte :
elles sont à considérer comme des équivalents indicatifs.
Source : https://github.com/bukowa/1000-common-words
